# Agent Tool-Use Reliability

Use this skill when building or debugging autonomous tool-use loops to ensure deterministic JSON schema conformance and zero hallucinated parameters.

## Core Patterns

### 1. JSON Schema Enforcement with Repair Contract

When an LLM outputs malformed JSON or invalid parameter types, do not abort immediately:

```typescript
import { z } from 'zod';

export async function executeToolWithRetry<T>(
  rawToolCall: { name: string; arguments: string },
  schema: z.ZodSchema<T>,
  executor: (args: T) => Promise<unknown>,
  maxRetries = 2
): Promise<unknown> {
  let rawArgs = rawToolCall.arguments;
  for (let attempt = 0; attempt <= maxRetries; attempt++) {
    try {
      const parsedJson = JSON.parse(rawArgs);
      const validated = schema.parse(parsedJson);
      return await executor(validated);
    } catch (err) {
      if (attempt === maxRetries) throw err;
      rawArgs = await repairJsonViaPrompt(rawArgs, err instanceof Error ? err.message : String(err));
    }
  }
}
```

### 2. Idempotency Keys on Mutating Tools

Every write, deploy, payment, or delete tool call must require an `idempotency_key` parameter generated by the agent based on task ID and turn index.
