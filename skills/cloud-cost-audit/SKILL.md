# Cloud & Agent Cost Audit

Use this skill when investigating excessive LLM token burn, runaway subagent recursion, unexpected cloud API usage, or webhook rate-limit spikes.

## Skill Stack

Pull these NEXUS-OS skills into the workflow when relevant:

- `autonomous-loops` for inspecting bounded loop execution and stop conditions
- `agentic-engineering` for tracing subagent tool-call graphs and recursion depth
- `token-budget-advisor` for optimizing context windows and compaction thresholds
- `search-first` before guessing API endpoints or billing metrics
- `verification-loop` for proving loop termination and quota compliance
- `tdd-workflow` when implementing unit tests to constrain token expenditure

## When To Use

- Subagent execution runs indefinitely or consumes excessive context tokens
- High volume of automated PRs or commit churn generated by background tasks
- API gateway or LLM provider billing surges
- Recursive webhook triggers or queue worker thrashing

## Scope Guardrails

1. Freeze active background tasks and inspect running agent loops first (`nexus loop-status`).
2. Identify token allocation bottlenecks: prompt bloat, oversized tool outputs, or circular reasoning.
3. Enforce context budget limits and structured compaction.
4. Add regression tests validating bounded loop termination.
