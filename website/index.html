Deterministic Red-Green-Refactor Engine

AI models left unconstrained hallucinate passing tests or write code without verification. NEXUS-OS strictly enforces the Test-Driven Development kernel:

  • ✓ Step 1 (Red): Agent must author an isolated failing unit test first and execute the test runner to prove failure.
  • ✓ Step 2 (Green): Implement the minimal code necessary to make the failing assertion pass cleanly.
  • ✓ Step 3 (Refactor): Clean architecture optimization without breaking the test suite boundary.
  • ✓ 80%+ Coverage Gate: Automated coverage verification blocks PR creation until coverage thresholds are satisfied.

SQLite Memory Vault via Model Context Protocol (MCP)

Say goodbye to context amnesia between sessions and tools. NEXUS-OS includes an embedded local SQLite vector & relational memory vault exposed directly through MCP.

  • ✓ 100% Local & Private: All notes, decisions, and architectural ADRs live in your repository SQLite database.
  • ✓ Cross-Harness Handoffs: Save a session context in Claude Code, resume it in Cursor IDE or OpenAI Codex seamlessly.
  • ✓ MCP Protocol Native: Automatically exposes `memory_search`, `memory_save`, and `memory_doctor` to any MCP client.

AgentShield & Zero-Trust AST Security

Autonomous agents can be exploited via indirect prompt injection or run unintended shell commands. AgentShield parses and checks agent actions before execution.

  • ✓ AST Command Gatekeeper: Intercepts bash commands to block `rm -rf`, curl-to-bash pipes, and unauthorized network egress.
  • ✓ Indirect Prompt Injection Defense: Sanitizes untrusted inputs from web scrapes, issue trackers, and dependency READMEs.
  • ✓ Entropy Secret Scanner: Shannon entropy scanning prevents committing API keys, tokens, or private certificates.

Everything you need to know about adopting NEXUS-OS in your development workflow.

Prompts alone do not enforce software engineering discipline. NEXUS-OS is a complete operating system layer that bridges model capabilities with deterministic development invariants. It gives agents structured roles (72 subagents), executable workflows (350 skills), ergonomic shortcuts (106 commands), persistent local memory (SQLite MCP), and a non-negotiable Red-Green-Refactor test driver.

NEXUS-OS works directly in your environment through native configuration surfaces. For Claude Code, it configures `.claude/` plugins and commands. For Cursor, it maps agents into `.cursorrules` and sets up the SQLite Memory Vault via `.mcp.json`. Installing via `npx nexus-os setup` automatically detects your active IDEs and configures them in seconds.
